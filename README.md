
# SaveAsBot Clone

Telegram-бот для скачивания видео/аудио через yt-dlp.

## Возможности
- TikTok
- YouTube
- Instagram Reels
- Отправка видео обратно в Telegram
- Автоочистка файлов

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

1. Создай бота через BotFather
2. Вставь токен в `.env`

```env
BOT_TOKEN=YOUR_TOKEN
```

3. Запусти:

```bash
python bot.py
```
